## Example projects

The public repository includes the demonstration projects "Breakfast at Home"
and "Preparing Pasta at Home", together with the images required to load them.
They are provided only to illustrate Sara workflows.

These materials do not depict or document identified users, patients, or real
therapy sessions. No personal or clinical data are intentionally included.

"Breakfast at Home" includes one demonstration WAV file referenced by the
project. Its content and provenance must be reviewed before each public
distribution. "Preparing Pasta at Home" does not include an associated audio
asset.

## Sara interface assets

The repository includes general interface icons and application assets required
to run Sara. Their provenance and release suitability should be verified as
part of the publication archive. The MIT License for Sara source code does not
automatically relicense third-party visual resources.
